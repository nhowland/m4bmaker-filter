Design notes

  • Placement. Above the model list, inside the choose panel only. It never appears in the “saved transcript” state, and never at wizard entry, because reusing a transcript never runs whisper-cli.
  • One banner, one accent. Same accent hue the app already uses for warnings, with a soft wash rather than a red error treatment: this is a setup step, not a failure.
  • Blocked Continue explains itself. The footer shows a short reason next to the disabled button, so the banner isn’t the only clue.
  • macOS shows a command; other platforms don’t. Only the Homebrew route has been verified, so Windows and Linux get a releases-page link and a plain “untested” note instead of a guessed command.
  • Re-check without restarting. A missed install shows “Still not found” in place; a hit removes the banner and enables Continue.
  • Themes. Both light and dark are covered by the same tokens as the other wireframes; toggle above.
  • Open (ADR-0056 question 3): whether the README should mention this banner once it exists. Not shown here; defaults to no README change until decided.
